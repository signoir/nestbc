# Seeder Documentation

This directory contains documentation for the database seeding functionality in the nestbc application.

## Available Documentation

- [Database Seeder Documentation](./database-seeder-documentation.md) - Complete documentation for the database seeder including roles, permissions, and admin user seeding

## Purpose

The seeder functionality provides initial data for the RBAC and ABAC authorization system, including:
- Default roles (admin, user, moderator)
- Basic permissions for different actions and subjects
- Super user with administrative privileges
